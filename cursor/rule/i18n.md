# Internationalization Rules (i18n)

## General Rules
- Do NOT hardcode strings in UI
- Always use stringResource(R.string.xxx)

## String Resources
- Extract all UI text into string resources
- Provide translations for:
  - Default (English) → values/strings.xml
  - Spanish → values-es/strings.xml
  - Vietnamese → values-vi/strings.xml

## Naming Convention
- Use clear and consistent keys
- Format:
  screen_element_description

### Examples:
- intro_title_1
- intro_desc_1
- button_next
- button_skip

## Compose Usage
- Always use:
  stringResource(R.string.xxx)

## AI Generation Rules
When generating UI:
- Automatically extract all text
- Generate strings.xml for all supported languages
- Avoid duplicate keys
- Keep translations natural (not literal if possible)

## Notes
- Review translations for accuracy if needed
