## Canonical reference: Notification feature

The Notification feature is the reference implementation.
All new features MUST follow the same structure:

```
NotificationDTO          data/model/response/
NotificationFactory      data/factory/
NotificationApi          data/remote/api/
NotificationRepoImpl     data/repo/           <- implements NotificationRepo
NotificationRepo         domain/repo/         <- interface only
INotification            domain/model/        <- interface only
NotificationUseCase      domain/usecase/
NotificationVM           presentation/viewmodel/
NotificationScreen       presentation/screen/notification/
```

Key rules:
- domain/model/ and domain/repo/ -> interfaces ONLY
- data/repo/ -> *RepoImpl implementing the domain interface
- VM depends on UseCase -- never on Repo directly
- UseCase wraps calls with withIO { }
- API uses ApiAsync<T>, never suspend or Call<T>
- Null-safe field access via .safe() in Factory (not ?: "")
- All coroutines in VM via launch(loading, error) { }
- Colors from Color.kt only -- never Color.White / Color.Black / Color(0xFF...)
- Strings via stringResource(R.string.xxx) -- never hardcoded
